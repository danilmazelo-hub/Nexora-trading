# Карта разработчика — сверяйся сам

Это твоя личная карта, не системный prompt для агента. Здесь отмечаешь только то, что сам проверил. Подробности для агента находятся в [плане](EASYTRADE-IMPLEMENTATION-PLAN-RU.md). Все флажки изначально пустые: подготовка документов не означает выполнение проекта.

## Один рабочий цикл

Выбери первый незакрытый ID → прочитай его карточку → отправь агенту одну задачу → запусти проект → выполни действие ниже → прочитай результаты проверок → запиши commit/доказательство → поставь флажок → переходи дальше.

Если агент говорит «готово», но ты не можешь открыть и проверить результат, флажок остаётся пустым. При ошибке запиши действие, ожидание, факт и скриншот; верни агенту ту же задачу для исправления. Не проси переписать весь проект и не принимай удаление проверки как исправление.
