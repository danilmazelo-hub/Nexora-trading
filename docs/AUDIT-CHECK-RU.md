# Проверка NEXORA по классам ошибок из аудита Nexus Analyst (15.10.2026)

Аудит Nexus Analyst относится к другому продукту. Здесь NEXORA проверена по тем же классам ошибок; проверка выполнена в браузере на демо-данных.

| Аудит Nexus | Что проверено в NEXORA | Результат | Исправление |
|---|---|---|---|
| QA-01 · TP «за рынком» сразу закрывает сделку | Лимит Buy выше ask / Sell ниже bid | **Найдено (P1):** Buy-лимит ×1,5 к рынку исполнялся по лимиту — переплата $123 на 0,1 ETH, без предупреждения | Такой лимит исполняется сразу по рыночной цене; в форме — предупреждение до отправки; отложенные лимиты исполняются по лучшей из цен; лимит дальше 50% от рынка — предупреждение |
| QA-04 · сумма выше максимума пополнения | Лимиты пополнения | **Найдено:** максимума не было | Мин./макс. ($10 / $100 000) в форме и на «сервере» одинаково; максимум настраивается в «Комиссиях» |
| QA-06 · Pending без следующего шага | Неоплаченная заявка | **Найдено:** «Ожидание перевода» висело бесконечно | Через 30 мин статус «Истекло», уведомление и подсказка «ничего не зачислено, создайте новую» |
| QA-07 · техническая ошибка JSON пользователю | Ошибки API / шлюза | Не найдено: ошибки переводятся в понятные сообщения | — |
| QA-02/03 · 0.0 Lot, −0.00 | Форматирование | **Найдено:** −$0,00 и округление малых объёмов | «<$0,01» / «<0,01%» со знаком; малый объём не показывается нулём |
| QA-10 · проценты прыгают ×100 | Изменение по всем 203 живым инструментам | Не найдено (все провайдеры в %, без смешения долей) | — |
| QA-11 · +0,00% при отсутствии данных | Неизвестное изменение | **Найдено:** неизвестное изменение показывалось бы как 0 | Показывается «—» |
| Forex · разный период процентов | Подпись периода | **Найдено:** везде «24h», хотя у акций/форекса/сырья — к закрытию сессии | Крипта — «24ч», остальное — «к пред. закрытию» (с подсказкой) |
| Устаревшая/закрытая котировка | Торговля при закрытом рынке | Добавлено предупреждение в форме ордера | — |
| QA-12 · неверная категория | Справочник | Не найдено (живой скот — агросырьё) | — |
| QA-13 · «Сохранено» при пустой форме | Профиль, смена пароля | Пароль: ошибки полей (ок). **Профиль:** «Сохранено» без изменений | «Изменений нет — сохранять нечего» |
| QA-14/15/17 · поля без подписей | 27 экранов кабинета, CRM, админки | Не найдено: у всех видимых полей/кнопок есть доступное имя | — |
| QA-16 · частичный перевод | EN-режим, 11 экранов; словарь | Не найдено: ни одной непереведённой строки, отсутствующих ключей нет | — |
| SEC · защита админ-операций | POST /api/live/config шлюза | **Найдено:** принимал запрос с любого сайта | Запросы с чужого Origin → 403 |

**Ограничения.** Сделки, платежи, авторизация и права в NEXORA — демо в браузере. Серверные проверки, идемпотентность, webhook-и платёжного провайдера, изоляция аккаунтов и аудит безопасности backend нужно выполнить при разработке сервера (см. `API_CONTRACTS.md`).
