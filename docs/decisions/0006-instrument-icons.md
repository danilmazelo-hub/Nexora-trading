# 0006. Иконки инструментов из прототипа

Дата: 2026-10-16. Статус: принято по решению владельца продукта. **Отступление от плана** (критерий D08 «В UI нет
чужих логотипов»).

## Контекст
В прототипе NEXORA (`legacy/nexora-demo`) у каждого инструмента была иконка: значки монет, логотипы компаний и индексов,
флаги валют. Новое приложение сначала строилось без них, по правилу плана. Владелец продукта попросил вернуть иконки,
как на старом сайте.

## Решение
- 141 иконка инструментов и 28 флагов скопированы из `legacy/nexora-demo/assets` в `apps/web/public/instruments/`.
  Соответствие символ → файл (`apps/web/src/modules/instruments/icons.data.ts`) сгенерировано из
  `legacy/nexora-demo/js/data/icons.js`. Покрыты все инструменты справочника и все валюты Forex.
- `InstrumentIcon`: у пары Forex два флага (базовая + котируемая валюта), у остальных — иконка актива; нет файла
  или ошибка загрузки — первые буквы символа. Иконка декоративная (`aria-hidden`), символ всегда написан рядом.
- Показывается в списке выбора инструмента, в заголовке инструмента и в карточке котировки (в том числе в watchlist).

## Последствия
- Логотипы компаний и токенов — товарные знаки их владельцев; файлы взяты из открытых наборов (CC0 / MIT, см.
  [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)). Лицензия набора не даёт права на товарный знак: перед
  публичным запуском это отдельная юридическая проверка. Иконки не означают партнёрства или одобрения.
- Логотипы бирж и провайдеров данных (Binance, Twelve Data) по-прежнему не показываются: источник цены указан текстом.
- Убрать иконки — удалить `InstrumentIcon` из трёх мест; данные и файлы изолированы.
