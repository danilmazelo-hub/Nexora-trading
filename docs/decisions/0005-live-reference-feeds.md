# 0005. Живые справочные цены поверх симулятора

Дата: 2026-10-16. Статус: принято (расширение адаптера D10, план — раздел «Живые справочные цены»).

## Контекст
Пользователь хочет видеть реальные цены там, где есть доступный для демо источник. План допускает это как
необязательное расширение `MarketDataProvider` после готового симулятора. Условия: кешировать на сервере, не смешивать
live / delayed / EOD, справочная цена не является исполнением сделки, демосчёт не превращается в реальный.

## Решение
- Источник выбирается **по рынку инструмента** (`apps/api/src/modules/market-data/live/`), включается переменной
  `MARKET_LIVE_FEEDS` (`binance`, `twelvedata`; пусто / `off` — только симулятор). Рынок без источника остаётся на
  симуляторе с явной пометкой.
- **Crypto — Binance Spot public market data** (`data-api.binance.vision`, без ключа): котировка из 24h-тикера (реальные
  bid/ask, изменение к цене 24 ч назад), свечи `klines`, стакан `depth` (`GET /market/instruments/:id/orderbook`).
  Пары к USDT; в интерфейсе подпись «USDT ≈ USD». Опрос раз в 2 с только для инструментов, которые кто-то смотрит
  (60 с после последнего запроса), пачками до 100 символов.
- **Forex, акции США и драгметаллы — Twelve Data (Basic: 8 кредитов/мин, 800/сутки, 1 кредит за символ)**, один общий
  бюджет (`TWELVEDATA_MARKETS=forex,stocks,metals`). Драгметаллы — XAU/XAG/XPT/XPD к USD; энергоносители и агротовары
  тарифом не покрыты. Символ, на который тариф отвечает отказом (403 / «available starting with…»), запоминается и
  обслуживается симулятором. Проверено 2026-10-16 на Basic: все 49 акций справочника и XAU/USD доступны; XAG, XPT, XPD,
  индексы (SPX, NDX) и WTI — нет. Инструмент, открытый на графике, —
  обновление раз в `TWELVEDATA_FOCUS_REFRESH_SEC` (60 с); другие пары в потоке — раз в 15 мин; прочитанные один раз —
  раз в 30 мин; между обновлениями всё из серверного кеша. Фоновым парам отдаётся не более 60 % суточного лимита, остаток
  бережётся для открытой пары и графиков. История кешируется на пару+интервал (5 мин…1 ч). Ответ 429 ставит паузу до
  конца минуты / суток UTC. Статус котировки — `delayed` («С задержкой»), а не `live`. Bid/ask у Twelve Data нет —
  применяется демо-спред вокруг цены.
- Живые источники работают только при часах `REALTIME`. Фиксированные часы (демосценарии, тесты) — всё на
  детерминированном симуляторе. Integration-тесты принудительно ставят `MARKET_LIVE_FEEDS=off` и не ходят в сеть.
- Нет данных → `unavailable` / `stale`, ноль не подставляется; нет истории (лимит, сбой) → 503 `QUOTES_UNAVAILABLE`,
  а не пустой или симулированный график.
- Ключи — только в `apps/api/.env` (вне git). URL с ключом не попадает в логи и ответы API.

## Не сделано (нужны ключи / доступ)
- **Акции — Alpaca Basic (IEX), live watchlist до 30 символов**: нужны `ALPACA_KEY_ID`/`ALPACA_SECRET_KEY`;
  `data.alpaca.markets` из текущей сети не отвечает. Пока акции идут через Twelve Data (статус «С задержкой»).
- **Индексы — Massive Indices Basic, пометка «по итогам дня»**: нужен ключ Massive; потребуется статус `eod`.
- **Сырьё кроме драгметаллов — история из внешнего источника** (например, EIA для энергоносителей, нужен ключ) + явно
  помеченный симулятор для демосделок.

## Последствия
- Цены crypto/forex совпадают с рынком, но остаются справочными: сделки (D15+) исполняются в демо по этим ценам.
- Перед публичным показом проверить условия использования данных каждого провайдера (бесплатный ключ не гарантирует
  права публичного отображения).
- `GET /market/status` показывает активные источники и расход кредитов Twelve Data; `GET /capabilities` —
  `priceSource: "simulator+binance+twelvedata"`.
