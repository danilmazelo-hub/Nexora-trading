# 0004. Библиотека графиков: TradingView Lightweight Charts 5

Дата: 2026-10-16. Статус: принято (D13).

## Контекст
D13 требует подключить библиотеку графиков после проверки лицензии; в интерфейсе не должно быть чужих логотипов.

## Проверка лицензии
- Пакет `lightweight-charts@5.2.1`, лицензия **Apache-2.0** (`node_modules/lightweight-charts/LICENSE`): разрешено
  коммерческое и некоммерческое использование, изменение и распространение с сохранением уведомлений.
- README пакета требует разместить уведомление об авторстве и ссылку на https://www.tradingview.com/ на странице,
  доступной пользователям. Опция `layout.attributionLogo` (по умолчанию `true`) выводит логотип-ссылку на графике.

## Решение
- Используем `lightweight-charts` 5.2.1 (canvas, ~45 КБ gzip, свечи, шкалы, кроссхейр, без зависимостей).
- Логотип отключён (`attributionLogo: false`) — правило D08 «нет чужих логотипов». Вместо него под каждым графиком
  выводится текстовое уведомление «Графики: TradingView Lightweight Charts™ © TradingView, Inc.» со ссылкой на
  https://www.tradingview.com/, и уведомление продублировано в [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md).

## Последствия
Обновление библиотеки — с повторной проверкой лицензии и требований к атрибуции.
