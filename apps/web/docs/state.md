# Состояние

| Данные | Источник | Время жизни |
|---|---|---|
| Ответы сервера (сессия, счета, остатки, справочник, свечи) | TanStack Query | до инвалидации; `clear()` при reset/выходе/401 |
| Котировки | TanStack Query `['quote', id]`, наполняется SSE `quoteStream` | пока есть подписчики + `gcTime` |
| Выбранный инструмент, вкладка, период графика | URL (`?symbol=`, `?period=`) | история браузера |
| Открытый диалог, тосты | локальный state / `ToastProvider` | до закрытия |

Нельзя: хранить копию ответа API в `useState`, хранить баланс в localStorage, вычислять авторитетные суммы на клиенте.
